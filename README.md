# 🚀 Suvidha AI Career Portal | Sanskriti HackIndia 2026

**Suvidha Career Portal** is a comprehensive AI-powered educational and career guidance platform designed to empower students in their academic and professional journey. From finding the right colleges to solving complex academic problems instantly and booking 1-on-1 mentorship sessions, this platform acts as a personal digital mentor.

---

## ✨ Key Features & Working

### 1. 🧠 Suvidha-AI Question Solver (Scan & Solve)
An intelligent scanner that recognizes handwritten or printed academic questions and provides instant, step-by-step solutions.
- **Working:** Users can upload a photo, scan from the camera, or type the question directly. The image/text is processed using the Google Gemini 1.5 Flash engine, returning high-speed and accurate mathematical/logical reasoning.
- **Regional Intelligence:** Solutions are provided in a mix of Hindi and English (Hinglish) for better conceptual clarity tailored to Indian students.

### 2. 🏛️ Smart College & School Directory (Regional Focus)
A meticulously curated database of educational institutions prioritizing regional empowerment, specifically focusing on Jammu & Kashmir (Rajouri, Budhal, Samba, etc.).
- **Working:** The "Explore Hub" lists regional gems (e.g., BGSBU, GMC Rajouri, GDC Budhal, JNVs) with accurate local campus images and verified data.
- **Comparison Engine:** Users can select multiple colleges and compare them side-by-side based on fees, accreditation (NAAC), facilities, and streams offered.
- **Dedicated Profiles:** Each institution has a dedicated, beautifully designed glassmorphism profile page detailing its infrastructure, faculty, and admission workflows (e.g., CUET, NEET-UG).

### 3. 🎯 AI Career Roadmap & Mentorship
- **Working:** Students can input their current status and target role, and the AI (Gemini) instantly generates a personalized semester-by-semester roadmap.
- **Expert Partners:** Integration of a "Book Session" feature allowing students to schedule 1-on-1 career guidance sessions with industry experts (e.g., IIT Alumni, Google/Amazon engineers).

### 4. 💼 Opportunity Hub (Jobs & Internships)
Integrated directly via API to provide real-time job and internship listings.
- **Working:** Fetches the latest tech, science, and arts roles. Students can view salaries, remote options, and directly apply, making the transition from education to employment seamless.

### 5. 🤝 Government & NGO Portals
- **Working:** Dedicated authentication formats for Government officials and NGOs to log in, track regional educational metrics, and provide funding or scholarships to marginalized students.

## 🛠️ Tech Stack

### Frontend & UI
- **Core:** HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Design System:** Custom CSS Grid/Flexbox with Glassmorphic design tokens.
- **Icons:** Standardized scalable assets.

### AI Engine & Backend 
- **AI Brain:** Google Gemini 1.5 API for Question Solving and Career Roadmap generation.
- **Backend:** Python Flask (Handles server-side processing, API proxying, and CORS).
- **Ecosystem:** Node.js / Vite used for isolated intelligence modules (`HACATHON-MATHURA`).

## 🚀 Getting Started

### Prerequisites
- Node.js (for the AI Engine module)
- Python 3.10+ (for the Backend API)

### Installation & Demo Setup

1. **Clone the Repo:**
   ```bash
   git clone https://github.com/crazy-develop/sanskriti-hackindia.git
   cd sanskriti-hackindia
   ```

2. **Start the AI Engine:**
   ```bash
   cd HACATHON-MATHURA
   npm install
   npm run dev
   ```
   *The engine will run on http://localhost:3000*

3. **Start the Python Backend (Optional):**
   ```bash
   python app.py
   ```
   *The backend will run on http://localhost:5000*

4. **Launch the Main Platform:**
   Use a local live server (e.g., VS Code Live Server) to open `index.html` in your browser.
